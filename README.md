# Rego Syntax

Highlights Open Policy Agent (OPA) Rego `.rego` files in Orca: packages, rules, keywords, built-in calls, strings with interpolation, numbers and comments.

The TextMate grammar is from the Apache-2.0 licensed [open-policy-agent/vscode-opa](https://github.com/open-policy-agent/vscode-opa) at commit `9291e7c81d3656b1005e5a323834d837a321f979`, converted from plist to JSON, otherwise unchanged. Its license is in `syntaxes/rego-LICENSE.txt`.

## Install

Requires Orca 1.4.246 or newer. Install from the community catalog at <https://www.onorca.dev/plugins/royklo/orca-rego>.
